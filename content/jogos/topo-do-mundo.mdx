# Topo do Mundo

É um party game com plataforma e Smash Bros, no qual o objetivo é ficar em uma posição maior que as dos outros, ganhando pontos. Para isso, cada jogador possui uma habilidade escolhida de plataforma (como dash) e pode pegar itens espalhados pelo mapa para atrapalhar os outros jogadores.

Feito e desenvolvido para eventos, sendo aprimorado conforme feedback.
